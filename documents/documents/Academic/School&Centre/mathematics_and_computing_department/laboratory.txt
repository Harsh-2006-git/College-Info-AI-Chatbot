Laboratories

1. Data Science Lab (DSL)
The Data Science Lab has been dedicated to provide a platform to students where theoretical lectures can be translated into practical implementation through programming models and tools. In Data Science Lab, our steady focus is to find the solutions of data-driven problems of Data Engineering, Data Analysis, Data Science, Artificial Intelligence and Machine Learning so that data can be transformed into valuable insights. PYTHON is a highly productive scripting language that is used to provide high productivity and performance to process large amounts of data in data science. The students can practice other programming languages like C, C++, JAVA and MATLAB also. Once students understand how to use a language, they can write the source code in a text editor, execute it on an interpreter, or compile it for execution. Students try different approaches for invoking and executing PYTHON scripts and complete PYTHON coding exercises. In Data Science Lab, students perform experiments, gain experience and move forward.

2. Computing Lab
The Computing Lab is very useful for the students, engineers, scientists & researchers. Millions of engineers and scientists worldwide use MATLAB for a range of applications in industry, including deep learning and machine learning, signal processing and communications, image and video processing, control systems, test and measurement, and computational finance. Students learn how to solve Numerical Analysis problems by using MATLAB. Numerical method is a mathematical tool designed to solve numerical problems. Numerical methods give us approximate results as there are always some assumptions made. The package MATLAB (matrix laboratory) provides an environment in which students can learn to program and explore the structure of numerical methods.
